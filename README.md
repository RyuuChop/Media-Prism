# MediaPrism 🌈

**One file in. Every format out.**

A 100% in-browser media converter — no uploads, no servers, no limits.

- **Images:** PNG, JPG, WEBP, ICO, GIF, BMP, SVG, TIFF, JPE
- **Audio:** MP3, WAV, AAC, OGG, M4A, FLAC

Everything runs locally in your browser using HTML5 Canvas, the Web Audio API,
and custom binary encoders — your files never leave your device.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
